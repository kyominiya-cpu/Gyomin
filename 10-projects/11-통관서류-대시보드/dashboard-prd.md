# 와인 수입 통관서류 검토 대시보드 PRD

> 생성일: 2026-06-14
> 생성 방법: dashboard-prd skill (대화형)
> 작성: 교민 (와인 수입사 BM / 무역·통관 담당)
> 유형: **로컬 웹 대시보드 + 서류 폴더링 워크플로우 (하이브리드)**

---

## 0. 한 줄 요약

와이너리(공급사)별 통관 서류 진행 현황을 **한눈에 보고**, 공급사에게 받은 필수 서류를 **대시보드에 끌어다 넣으면 시스템이 종류를 자동 판별해 규칙대로 폴더링·이름변경하여 저장**하고, 현황은 **통합 마스터 엑셀로 다운로드**, 빠진·오류 서류는 **공급사 요청 메일 초안**까지 만드는 로컬 도구.

---

## 1. 프로젝트 개요

### 배경 (Pain Points)
- 신규 와인/신규 와이너리를 들일 때 검토할 통관 서류가 **국가(FTA 여부)·거래 유형(신규 와이너리/기존 거래처 신규품목/빈티지만 변경)·카테고리(스틸/스파클링/논알콜)에 따라 조건이 달라짐.**
- 현재 **두 개의 엑셀 파일**을 따로 관리 중:
  - `신규수입서류검토_MASTER_GM.xlsx` → **와이너리(공급사) 단위** 1회성 등록 서류 검토 (K-MFDS 등록, 은행정보, 주소 대조 등)
  - `품목별 통관_Checklist.xlsx` → **SKU(품목) 단위** 발주별 서류 체크 (거래처별 시트)
- 공급사가 보낸 서류 파일을 일일이 **수작업으로 이름 바꾸고 폴더에 정리**해야 함.
- "뭐가 들어왔고 뭐가 빠졌는지" 한눈에 안 보임. 빠진 서류는 다시 공급사에 메일로 요청해야 함.

### 핵심 의사결정 (이 대시보드로 내리는 결정)
1. **이 와이너리/SKU는 통관 진행 가능한가, 아직 서류가 빠졌나?**
2. **공급사에게 무엇을(어떤 서류를) 추가 요청해야 하나?**
3. (v2) 받은 서류가 **규칙에 맞는가** (성분합 100%, SO2 한도, 주소 일치, 인증수출자번호 형식 등).

### 목적
조건별 필수 서류를 자동 판정하여 **현황 가시화 + 서류 자동 폴더링 + 누락분 요청**까지 한 흐름으로 처리한다.

### 핵심 가치
1. **조건 자동 분기** — 국가/거래유형/카테고리만 정하면 필수 서류 목록이 자동 산출
2. **한눈에 현황** — 와이너리별 진행률(받은 서류/필수 서류)을 카드로, **현황 Excel 다운로드**로 공유·백업
3. **자동 분류 + 폴더링** — 서류 업로드 시 **종류를 자동 판별**해 규칙대로 폴더·파일명 정리해 저장 (사용자 지정 불필요)
4. **요청 자동화** — 빠진/오류 서류에 대한 공급사 메일 초안 생성

### 사용자 / 빈도 / 대시보드 유형
- 사용자: 교민(BM/무역담당) 본인, 필요 시 동료 BM
- 빈도: 신규 수입·발주 건 발생 시 수시 (운영성)
- 유형: **운영 대시보드(Operational)** — "지금 무슨 서류가 빠졌나"를 보고 즉시 행동

## 2. 데이터 소스

### 소스 1: 통합 마스터 엑셀 (신규 — 두 파일 병합)
- **위치**: 로컬 (예: `C:\Users\kyomi\OneDrive\바탕 화면\통관서류_MASTER.xlsx`) — 경로 확정 필요
- **형태**: Excel (.xlsx), 멀티 시트
- **구성**: 기존 두 파일을 한 파일로 합치고 시트로 분리
  - **시트 `와이너리`** ← `신규수입서류검토_MASTER_GM` 기반 (와이너리 단위)
  - **시트 `품목(SKU)`** ← `품목별 통관_Checklist` 기반 (SKU 단위, 거래처 구분 컬럼 추가)
  - **시트 `규칙`** ← 분기·검증 규칙 (사람·시스템 공용 참조)
- **비고**: 대시보드는 이 파일을 읽어 화면을 그리고, 업로드/검토 결과를 **이 파일에 다시 기록**.

#### 소스 1-A 원본: `신규수입서류검토_MASTER_GM.xlsx` (와이너리 단위)
- 단일 시트(`2603` = 월 코드). 2행 그룹 헤더.
- 컬럼 그룹: 진행사항(시작일/종료일/소요일) · 공급사정보(공급사코드/거래처코드/공급사명/국가/담당자/연락처/BM) · 통관확인 · 총진행SKU
- **서류 검토 그룹 (A~G)** ← 폴더링 규칙의 알파벳 기준:
  | 그룹 | 포함 항목 |
  |------|-----------|
  | **A. K-MFDS** | 제조업소코드 / 업소명 / 주소 / 등록만료일 |
  | **B. 공급사정보** | 병입지등록증 / 사업자등록증 / (서류상)공급사명 / 등록주소 |
  | **C. BTL & 라벨** | BTL / 전면 / 후면 / QR |
  | **D. Ingredient list** | 성분표 |
  | **E. Flow Chart** | 공정도 |
  | **F. 병입증명서** | 해외 식약처 등록 주소·업소명·품목·병입일자 포함 |
  | (원산지증명서) | 선적일로부터 1년 / 미국만 필요 (EU는 인보이스 FTA 문구 있으면 불필요) |
  | **G. 은행정보** | 은행명/코드/계좌/지점/주소 |
- **주소 대조 포인트**: A의 K-MFDS 주소(업소명·주소) ↔ B의 서류상 등록주소가 일치해야 함.

#### 소스 1-B 원본: `품목별 통관_Checklist.xlsx` (SKU 단위)
- 거래처별 시트(AREE / ESMA / 쿤슬러 / FRAP / Korean version).
- 행 = SKU. 컬럼: `Code | Product | Variety | Vintage | (성분표/공정도/병이미지/전면/후면/한글라벨/병입증명서/K-MFDS…) | Remarks`
- ✓ = 서류 수령. Remarks: 신규 / Vintage updated / New item 등.
- 시트별 컬럼 차이 = 거래처 조건 차이(어떤 거래처는 K-MFDS·병입증명서 필요, 어떤 곳은 불필요).

### 조인 키
- 와이너리 ↔ SKU: **공급사코드 / 거래처코드** (예: ESOR, AREE, FRAP…) + 와이너리명
- SKU 식별: **SKU Code** (예: AREE003, FRAP004)

## 3. 조건 분기 & 검증 규칙 (핵심 자산)

> 이 규칙이 "필수 서류 목록 자동 산출"과 "검증(v2)"의 근거. 통합 엑셀의 `규칙` 시트 + 코드 양쪽에 반영.

### 3.1 분기 변수 (3축)
| 축 | 값 |
|----|-----|
| 거래/품목 유형 | ① 신규 와이너리 ② 기존 거래처-신규 품목 ③ 기존 거래처-기존 품목(빈티지만 변경) |
| FTA 여부 | FTA 적용국 / 미적용국(미국 포함) |
| 카테고리 | 일반 스틸 / 스파클링 / 논알콜 |

### 3.2 신규 와이너리 — 최초 1회 풀세트
공통 필수: 병입지 증명서, 성분표, 공정도, 병입날짜 증명서, SKU별 Bottle 이미지·전면·후면 라벨 이미지
추가: K-MFDS 해외 제조업소코드 확인, (해당 시) 사업자등록증/병입지등록증, 은행정보

**성분표(Ingredients) 검증 규칙:**
- 성분 합계 = **100%**
- 각 성분 **E코드** 부여 → *권장(경고만, 통관 차단 아님)*. ※ 교민이 "코드 필수" 성분 목록을 추후 업데이트 예정.
- 무수아황산(이산화황) ≤ **0.034%**
- **0% 표기 성분 금지** (예: 소브산 0% → 표에서 삭제되어야 함)

**주소 교차 검증 (신규 와이너리 핵심):**
- 후면 라벨 · 성분표 · 공정도 · 병입지 증명서의 주소 = **K-MFDS 등록 해외제조업소 주소**와 모두 일치/매우 유사
- 불일치 시 → 두 주소의 관계 증명 문서(소유 관계 증명 문구/공식 문서) 필요

**문서 통합 허용:** 여러 항목이 한 파일에 들어가도 OK (예: 성분표에 병입날짜 포함).

### 3.3 기존 거래처
- **신규 품목**: 병입 장소 변경 여부 확인 → 변경 없으면 병입증명서 불필요
- **기존 품목, 빈티지만 변경**: 병입장소·성분표·공정도 변경 여부 확인 → 변경 없으면 추가 서류 불필요

### 3.4 FTA 적용국
- **통관은 CI(Commercial Invoice) 기준**
- CI에 **인증수출자 번호 + 원산지 신고 문구 필수**
- 프랑스 코드 체계: 국가(2)+세관부호(6)/인증번호(4) → 예 `FR004440/0134`
- 원산지 표기: EU / EC / 국가명(FRANCE) 사용 가능. **EEC 표기는 불인정.**
- 신고 문구 예: *"The exporter of the products covered by this document (customs authorisation No. FR004440/0134) declares that, except where otherwise clearly indicated, these products are of EU preferential origin."*

### 3.5 FTA 미적용국 (미국 포함)
- 전 품목: **병입 증명서** 필요
- 전 품목: **원산지 증명서** 필요 — Blanket Period는 선적일 포함, 선적일로부터 **1년 유효**

### 3.6 카테고리 추가 규칙
- **스파클링**: 전 품목 성분 정보 필요
- **논알콜**: 영양성분표 필수

## 4. 서류 자동 폴더링 규칙 ★

> 대시보드의 핵심 워크플로우. 업로드된 서류를 아래 규칙대로 저장.

### 4.1 저장 위치 (폴더 구조)
```
C:\Users\kyomi\OneDrive\바탕 화면\신규통관서류\
   └─ [와이너리명]\                         ← 와이너리별 하위 폴더 자동 생성
        ├─ A_KMFDS__<원래파일명>.pdf
        ├─ B_BottlingSiteRegistration__<원래파일명>.pdf
        ├─ B_BusinessRegistration__<원래파일명>.pdf
        ├─ C_Bottle__<원래파일명>.jpg
        ├─ C_FrontLabel__<원래파일명>.jpg
        ├─ C_BackLabel__<원래파일명>.jpg
        ├─ D_Ingredients__<원래파일명>.pdf
        ├─ E_FlowChart__<원래파일명>.pdf
        ├─ F_BottlingCertificate__<원래파일명>.pdf
        ├─ CertificateOfOrigin__<원래파일명>.pdf   (미국 등 FTA 미적용국)
        └─ G_BankInfo__<원래파일명>.pdf
```

### 4.2 파일명 규칙
```
[알파벳]_[영문서류명]__[기존 서류 원래 이름].[확장자]
```
- **알파벳**: 마스터 엑셀의 서류 그룹(A~G) 첫 글자
- **영문서류명**: 서류 종류를 영어로
- **__(언더스코어 2개)**: 구분자
- **기존 원래 이름**: 공급사가 보낸 파일명 그대로 보존
- 예: `D_Ingredients__CODORNIU ingredient list 2026.pdf`

### 4.3 서류 그룹 ↔ 영문명 매핑
| 알파벳 | 서류(한글) | 영문 파일명 토큰 |
|--------|-----------|------------------|
| A | K-MFDS 제조업소 등록 | `A_KMFDS` |
| B | 병입지 등록증 | `B_BottlingSiteRegistration` |
| B | 사업자등록증 | `B_BusinessRegistration` |
| C | 병 이미지(BTL) | `C_Bottle` |
| C | 전면 라벨 | `C_FrontLabel` |
| C | 후면 라벨 | `C_BackLabel` |
| C | QR | `C_QR` |
| D | 성분표 | `D_Ingredients` |
| E | 공정도 | `E_FlowChart` |
| F | 병입 증명서 | `F_BottlingCertificate` |
| (—) | 원산지 증명서 | `CertificateOfOrigin` |
| G | 은행 정보 | `G_BankInfo` |

> **자동 분류 (v1 핵심):** 사용자는 서류 종류를 **지정하지 않는다.** 파일을 업로드하면 시스템이 **내용을 직접 읽어 어떤 서류인지 판별** → 해당 알파벳·영문명을 자동 부여 → §4.1 규칙대로 폴더명·파일명을 변경하여 저장.
> - PDF/문서: `kordoc` MCP·PDF 파싱으로 텍스트 추출 후 분류 (성분표/공정도/병입증명서/CI/원산지증명서/K-MFDS/사업자등록증 등 키워드·구조 기반)
> - 이미지(병/라벨): 비전 판독으로 병 이미지 / 전면 / 후면 라벨 구분
> - **분류 신뢰도가 낮으면** 추정 결과를 제시하고 사용자에게 확인받음(fallback). 사용자가 수정하면 그 결과를 학습용 매핑에 반영.

## 5. 대시보드 화면 (기능 정의 — 시각 위계는 디자인 툴 위임)

> "무엇을 보고 무엇을 결정하는가"만 정의. 컴포넌트/레이아웃/차트유형/색상은 디자인 단계에서 결정.

### View 1: 와이너리 현황 (메인) — "지금 어느 와이너리가 통관 준비 완료/미완인가?"
**표시 항목 (우선순위 순):**
| 순위 | 항목 | 비고 |
|------|------|------|
| 1 | 와이너리명 + 국가 + FTA여부 뱃지 + 거래유형(신규/기존) | 조건 한눈에 |
| 2 | 서류 진행률 (받은 필수서류 / 전체 필수서류) | 예: 6/9 |
| 3 | 빠진 서류 개수 / 경고 개수 | 클릭 시 상세 |
| 4 | 담당 BM, 시작일/소요일 | |

**데이터 관계 (보고 싶은 것):**
| 순위 | 관계 |
|------|------|
| 1 | 와이너리별 진행률 분포(완료/진행중/미착수) |
| 2 | 국가·FTA여부별 건수 |

**필터**: 국가 / FTA여부 / 거래유형 / 카테고리 / 담당BM / 진행상태
**데이터 투명성**: 각 와이너리의 마지막 갱신 시점 표시.

**현황 Excel 다운로드 버튼 (메인 화면 상단):**
- 현재 대시보드에 표시된 통합 현황(와이너리 + SKU + 서류 체크 상태)을 **하나의 Excel 파일로 내보내기**.
- 통합 마스터 파일과 동일한 시트 구조(와이너리 / 품목 / 규칙)로 생성. 적용 중인 필터 상태 반영.
- 파일명: `통관현황_YYYY-MM-DD.xlsx` (다운로드 시점 날짜).
- 용도: 보고·공유·백업. 대시보드를 못 켜는 동료도 엑셀로 현황 확인 가능.

### View 2: 와이너리 상세 — "이 와이너리에 무슨 서류가 있고 뭐가 빠졌나? 무엇을 요청하나?"
- **필수 서류 체크리스트** (조건 자동 판정으로 생성): 각 항목 상태 = 받음 ✅ / 없음 ❌ / 불필요 ⚪ / 경고 ⚠️
- **서류 업로드 영역**: 드래그&드롭 → **시스템이 서류 종류 자동 판별**(§4.3) → §4 규칙대로 폴더링 저장 + 체크칸 ✅ 갱신. (분류 불확실 시에만 확인 요청)
- **주소 대조 패널**(신규 와이너리): K-MFDS 주소 vs 서류상 주소 나란히 비교
- **공급사 요청 메일 초안 버튼**: 빠진/오류 서류 목록을 담은 영문 메일 초안 생성 (담당자·연락처 자동 채움)

### View 3: SKU(품목) 현황 — "거래처별 SKU 서류 체크"
- 거래처(시트)별 SKU 테이블: SKU코드 / 상품명 / 품종 / 빈티지 / 서류 체크 상태 / 비고(신규·빈티지변경)
- 빈티지만 변경된 SKU는 "변경 여부 확인" 플래그 표시

### AI 인사이트 제안 패널
| 유형 | 탐지 조건 | 예시 문구 |
|------|-----------|-----------|
| 누락 경고 | 필수 서류 미수령 | "[CODORNIU] 병입증명서 미수령 — 공급사 요청 필요" |
| 규칙 위반(v2) | 성분합 ≠ 100% / SO2 > 0.034% / 0% 성분 존재 | "[성분표] 합계 98.2% — 재확인 필요" |
| 주소 불일치(v2) | K-MFDS 주소 ↔ 서류 주소 상이 | "후면 라벨 주소가 K-MFDS 등록 주소와 다름 — 관계 증명 문서 필요" |
| FTA 문구 누락(v2) | CI에 인증수출자번호/신고문구 없음 | "Commercial Invoice에 인증수출자 번호 없음" |

**설계 규칙**: 결론이 아닌 제안 톤. 참조 데이터 명시. View당 3개 이하.

## 8. 범위 (Scope)

### v1 (먼저 만들 것)
- **두 엑셀 → 통합 마스터 1파일 병합** (시트: 와이너리 / 품목 / 규칙)
- 통합 마스터 엑셀 읽어 **와이너리 현황 + SKU 현황** 표시
- 메인 화면 **현황 Excel 다운로드 버튼**
- 조건 분기로 **필수 서류 목록 자동 산출** + 체크리스트
- 서류 업로드 → **종류 자동 분류**(내용 판독) → **§4 규칙대로 폴더링 저장** + 체크칸 갱신
- 공급사 **요청 메일 초안** 생성

### v2 (다음)
- 서류 **내용 자동 검증**: 성분합 100% / SO2 0.034% / 0% 성분 / 주소 대조 / 인증수출자번호 형식 (kordoc·PDF 파싱)
- 자동 분류 **정확도 고도화** (사용자 수정 피드백 학습, 신규 서류 유형 추가)
- "코드 필수" 성분 목록 사용자 편집 화면
