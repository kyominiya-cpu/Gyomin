# 알림 자동화 설정 가이드 (TradingView → 콕핏 웹훅)

TradingView가 **내가 그린 추세선**을 감시하다가 가격이 닿으면 콕핏으로 알림을 쏴줍니다.
앱 쪽(수신·표시·소리·브라우저 알림)은 이미 구현돼 있고, 아래 3가지만 교민 님이 세팅하면 됩니다.

> **필요 조건**
> 1. TradingView **Pro 플랜** 이상 (웹훅은 유료 기능, 약 $14.95/월~)
> 2. 로컬 앱을 외부에 노출하는 **공개 URL** (TradingView 클라우드는 `localhost`에 접속 못 함)
>
> Pro가 없다면? 앱의 **매수존 근접 판정**(채널 사냥 탭 뱃지)이 무료로 동작합니다. 현재가를 입력/갱신할 때 존 진입 시 브라우저 알림이 뜹니다. (단, 하루종일 자동 감시는 아님)

---

## 1단계 — 로컬 앱을 공개 URL로 노출 (터널)

앱을 먼저 실행: `npm run dev` (http://localhost:3000)

### 방법 A: Cloudflare Tunnel (무료, 계정 불필요, 추천)
1. `cloudflared.exe` 다운로드: <https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/>
2. 터미널에서:
   ```
   cloudflared tunnel --url http://localhost:3000
   ```
3. 출력에 `https://xxxx-xxxx.trycloudflare.com` 형태의 주소가 나옴 → 이게 공개 URL.

### 방법 B: ngrok
1. <https://ngrok.com> 가입 후 설치
2. `ngrok http 3000` → `https://xxxx.ngrok-free.app` 주소 획득

> ⚠️ 무료 터널은 껐다 켜면 주소가 바뀝니다. 주소가 바뀌면 TradingView 알람의 Webhook URL도 갱신해야 함.
> 상시 운용하려면 앱을 항상 켜두는 PC + 고정 터널(유료) 또는 클라우드 배포(로드맵 L5)가 필요.

**최종 Webhook URL** = `공개URL` + `/api/tv-webhook`
예: `https://xxxx.trycloudflare.com/api/tv-webhook`

## 2단계 — TradingView에서 추세선 알람 만들기

1. TradingView에서 종목 차트를 열고 **채널(추세선)을 그린다.** (평소대로)
2. **하단선(매수 자리)** 우클릭 → **알림 추가(Add Alert)**
   - 조건(Condition): 그 **추세선(Trend Line)**, **Crossing**(교차)
   - 옵션: **Once Per Bar Close** (종가 확정 시 1회 — 페이크 방지)
   - **Notifications 탭 → Webhook URL** 체크 → 1단계의 Webhook URL 붙여넣기
   - **Message** 박스에 아래 **매수 템플릿** 붙여넣기
3. **상단선(분할매도 자리)** 도 똑같이, **매도 템플릿** 으로 하나 더 생성

> 추세선 알람은 TradingView가 **기울기를 자동으로 추종**합니다 — 매일 값이 변해도 알아서 계산해서 닿을 때 쏩니다.

### 알람 Message 템플릿 (그대로 복사)

**매수 (하단선 알람):**
```json
{"ticker":"{{ticker}}","price":{{close}},"signal":"buy","message":"채널 하단 도달 — 매수 검토"}
```

**분할매도 (상단선 알람):**
```json
{"ticker":"{{ticker}}","price":{{close}},"signal":"sell","message":"채널 상단 도달 — 분할 매도"}
```

`{{ticker}}` `{{close}}` 는 TradingView가 실제 종목/가격으로 치환합니다.
`signal` 값(`buy`/`sell`)에 따라 콕핏이 색·소리를 구분합니다.

---

## 3단계 — 콕핏에서 수신 확인

1. 콕핏 **채널 사냥** 탭 하단 "TradingView 알림 수신" 패널
2. **🔕 알림 켜기** 클릭 → 브라우저 알림 권한 허용 (존 도달 시 팝업+소리)
3. **테스트 발사** 버튼으로 수신 흐름을 먼저 확인 (TradingView 없이도 동작 검증)
4. 실제 알람이 오면 종목·신호·가격·시각이 뜨고, **확인** 처리 가능

---

## 참고 — 굳이 웹훅이 필요한가?

- **폰 푸시 알림만 원한다면** TradingView 앱이 이미 폰으로 알림을 줍니다 (웹훅 불필요).
- **웹훅의 진짜 가치**: 알림을 콕핏 장부에 자동 기록 + 나중에 **자동매매(L5)**로 이어지는 파이프라인(웹훅 → KIS API 주문)의 첫 단추.
- 즉 지금 웹훅을 붙여두면, 나중에 자동매매로 확장할 때 이 배관을 그대로 재사용합니다.
