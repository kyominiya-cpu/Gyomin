1. 터미널 (Terminal)
정의
텍스트 명령어로 컴퓨터를 조작하는 프로그램
우리가 보통 컴퓨터를 쓸 때는 아이콘을 클릭하고, 창을 드래그합니다.
터미널은 다릅니다. 글자를 입력해서 컴퓨터에게 지시합니다.
왜 이런 방식을 쓰나요?
정확함: "Downloads 폴더의 .pdf 파일 중 2024년에 만든 것만 삭제"
마우스로 하면? 일일이 확인하며 클릭
터미널로 하면? 조건을 정확히 지정해서 한 번에 처리
자동화: 같은 작업을 반복해야 할 때, 명령어를 저장해두고 재사용
원격 작업: 서버 컴퓨터는 화면이 없습니다. 터미널로만 접속해서 관리합니다.

5. 토큰 (Token)
정의
AI가 텍스트를 처리하는 기본 단위
사람은 글자나 단어 단위로 글을 읽습니다.
AI는 토큰 단위로 텍스트를 처리합니다.
토큰의 크기
토큰은 단어보다 작을 수도, 클 수도 있습니다.
영어의 경우:
"hello" → 1토큰
"unfortunately" → 3토큰 (un + for + tunately)
한국어의 경우:
한 글자가 보통 1~2토큰
"안녕하세요" → 약 5~7토큰
왜 토큰을 알아야 하나요?
AI 서비스는 토큰 단위로 비용을 계산합니다.
입력 토큰: 내가 보낸 메시지, 파일 내용
출력 토큰: AI가 생성한 응답
또한 AI가 한 번에 처리할 수 있는 토큰 수에는 한계가 있습니다.
이게 바로 Context Window입니다.
6. Context Window (컨텍스트 윈도우)
정의
AI가 한 번에 참조할 수 있는 정보의 총량
Context Window는 토큰 수로 측정됩니다.
Claude의 경우 약 200,000 토큰의 Context Window를 가집니다.
Context Window 안에 들어가는 것들
> Loading Plain Text code…
​
Context Window가 왜 중요한가요?
창문 크기가 정해져 있습니다.
대화가 길어지면 Context Window가 점점 채워집니다.
꽉 차면? 오래된 대화 내용이 밀려나갑니다.
> Loading Plain Text code…
​
그래서 처음에 말한 내용을 AI가 잊어버리는 것처럼 보입니다.
실제로는 Context Window 밖으로 밀려났기 때문입니다.
Context Window 관리 방법
1. /compact 명령어
대화 내용을 요약해서 토큰을 절약합니다.
10,000토큰짜리 대화를 1,000토큰 요약으로 압축합니다.
> Loading Plain Text code…
​
2. 새 대화 시작
완전히 다른 주제로 넘어갈 때는 새 대화를 시작하는 게 효율적입니다.
3. CLAUDE.md 파일 활용
매번 설명해야 하는 프로젝트 정보는 CLAUDE.md 파일에 적어둡니다.

4. 필요한 파일만 읽기
"이 폴더 전체 읽어줘"보다 "config.json 파일 읽어줘"가 토큰을 아낍니다.

Claude에는 여러 버전이 있고, 각각 특성이 다릅니다.

9. Python
정의
프로그래밍 언어의 한 종류
프로그래밍 언어는 컴퓨터에게 할 일을 지시하는 언어입니다.
Python은 그중에서 문법이 간결하고 읽기 쉬운 언어입니다.
왜 Python을 알아야 하나요?
Claude Code가 자동화 코드를 만들 때 Python을 자주 사용합니다.
> Loading Python code…
​
직접 작성할 필요는 없지만, Claude Code가 만든 코드가 뭘 하는지 대략 이해하면 소통이 쉬워집니다.
Python이 필요한 작업들
파일 대량 처리 (이름 변경, 정리, 변환)
웹에서 데이터 수집
엑셀/CSV 데이터 가공
API 연동 자동화
설치: "Python 설치해줘"라고 Claude Code에게 요청하면 안내해줍니다.
10. Git
정의
파일의 변경 이력을 관리하는 도구
문서 작업할 때 이런 경험 있나요?
보고서_최종.docx
보고서_최종_수정.docx
보고서_진짜최종.docx
Git은 이 문제를 해결합니다.
파일 하나만 유지하면서
언제, 무엇이, 왜 바뀌었는지 기록하고
필요하면 과거 버전으로 돌아갈 수 있습니다
핵심 용어
용어
	
의미

Git으로 관리되는 폴더


Commit
	
변경사항을 기록하는 행위

Pull
	
원격 서버 기록을 내 컴퓨터로 다운로드
왜 중요한가요?
Claude Code도 Git을 사용합니다.
파일을 수정하기 전에 현재 상태를 기록해두므로, 문제가 생기면 되돌릴 수 있습니다.
사용: "커밋해줘", "푸시해줘"라고 Claude Code에게 요청하면 됩니다.

12. 환경변수 (Environment Variable)
정의
운영체제에 저장되는 설정값
API 키 같은 민감한 정보를 코드에 직접 쓰면 위험합니다.
코드가 유출되면 API 키도 함께 유출되니까요.
환경변수는 이런 정보를 코드 바깥에 저장하는 방법입니다.
왜 알아야 하나요?

이때 당황하지 않고, "환경변수 설정해줘"라고 Claude Code에게 요청하면 됩니다.
