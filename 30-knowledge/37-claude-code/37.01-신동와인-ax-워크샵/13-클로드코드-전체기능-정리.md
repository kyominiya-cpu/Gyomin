실전 가이드 — 자주·유용하게 쓰는 것만
이림 작업 맥락(AX 컨설팅·PKM·콘텐츠, 비개발 중심) 기준으로 진짜 써먹을 것만 추려 설명. 나머지 전체 목록은 아래 카탈로그 참조.
A. 대화 길어질 때 — 컨텍스트 관리 (제일 자주 씀)
긴 세션은 결국 컨텍스트가 차서 느려지고 헛소리가 늘어난다. 이걸 다스리는 4종이 핵심.
/clear — 주제가 완전히 바뀌면 그냥 새로 시작. 앞 대화가 다음 작업을 오염시키는 걸 막는다. "이 작업 끝, 다른 일" 하기 전 습관처럼.
/compact [지시] — 대화는 이어가되 길이만 줄이고 싶을 때. /compact 회신 관련 내용만 남겨 처럼 남길 초점을 지시할 수 있다. /clear는 다 버리고, /compact는 요약해서 들고 간다.
/context — 지금 컨텍스트가 얼마나 찼는지 그리드로 본다. 느려졌다 싶으면 먼저 이걸로 확인하고 compact/clear 판단.
/rewind(/undo) — 프롬프트가 꼬여서 엉뚱하게 흘렀을 때 그 지점으로 되돌린다. up to here로 고르면 그 지점까지를 요약으로 대체해 토큰도 아낀다.
B. 결과를 빼내기 — 복사·내보내기
/copy — 대화를 통째로 시스템 클립보드에 복사. 드래그 없이 결과를 다른 곳에 붙여넣을 때. (영상에서 "가장 자주 쓴다"고 강조한 것)
/export [파일] — 대화를 파일로 저장. 나중에 PKM에 남기거나 기록용으로.
C. 속도·강도 조절
/model — 가벼운 일은 sonnet/haiku, 어려운 일은 opus. 작업 난이도에 맞춰 바꾸면 속도·비용이 달라진다.
/effort — 같은 모델이라도 추론 강도를 조절. 단순 작업은 낮춰서 빠르게, 복잡한 판단은 높여서 꼼꼼하게.
/fast — Opus 그대로 두고 출력만 빠르게. 모델을 낮추지 않으면서 답답함만 줄이고 싶을 때.
D. 곁가지·소소하지만 유용
/btw <질문> — 본 작업 흐름을 안 깨고 잠깐 다른 질문. 메인 작업 컨텍스트는 그대로 유지. "이거 하다 갑자기 궁금한 거" 생길 때.
/powerup — 대부분 놓치는 기능을 하나씩 가르쳐주는 튜토리얼. 새 기능 익힐 때 틈틈이.
E. 나만의 자동화 만들기 (이림이 이미 쓰는 영역)
반복 작업을 굳히는 4단 사다리. 간단 → 복잡 순.
커스텀 명령(.claude/commands/*.md) — 자주 쓰는 프롬프트를 /이름으로 저장. $ARGUMENTS로 인자 받고, !명령으로 bash 출력, @파일로 파일 내용을 끼워넣는다. 가장 가벼운 자동화.
Skills — 여러 파일·스크립트·단계가 필요한 복잡한 작업. Claude가 상황 보고 알아서 발동(예: 세금계산서 얘기 나오면 tax-invoice). 이림 PKM에 이미 수십 개 깔려 있는 그것.
Subagents(/agents) — 무거운 일을 독립 컨텍스트의 전용 일꾼에게 위임. 메인 대화가 안 더러워지고, 여럿을 병렬로 돌릴 수 있다.
Hooks(/hooks) — "X 할 때마다 자동으로 Y"는 메모리·지침으로 안 되고 훅으로만 된다(harness가 직접 실행). 커밋 전 검사, 작업 후 알림 같은 자동 트리거.
F. 무거운 작업 한 번에
플랜 모드(/plan) — 바로 손대지 말고 설계부터. 큰 작업은 계획을 먼저 받아 검토 후 진행하면 헛수고가 준다.
백그라운드(bg) — 오래 걸리는 작업을 뒤로 돌리고 다른 일. 끝나면 자동 알림이라 들여다볼 필요 없다.
워크플로 / /batch — 비슷한 일을 많이 = /batch(반복 병렬), 하나의 복잡한 목표 = 워크플로(조사·실행·검증·통합까지). 단, 멀티 에이전트라 토큰을 많이 쓴다.
deep-research — 웹을 여러 갈래로 뒤져 출처 검증까지 한 보고서. 막연하면 먼저 범위를 좁히는 질문을 되묻는다.
G. 외부 연결
MCP(/mcp) — Gmail·캘린더·드라이브·브라우저(Playwright) 같은 외부 도구를 클로드에 물린다. 이림 환경엔 이미 연결돼 있어서 "메일 확인", "일정 등록" 같은 게 된다.
위가 실전 핵심. 아래는 전체 목록(니치 기능 포함) 빠른 참조.

세션 시작 시 자동 로드되는 지침 파일. 7단계 계층이 모두 병합된다.

Auto Memory: Claude가 작업 중 패턴·선호를 ~/.claude/projects/<proj>/memory/에 자동 기록. MEMORY.md 인덱스는 매 세션 첫 200줄(또는 25KB)만 자동 로드
HTML 주석: CLAUDE.md 내 <!-- -->는 Claude에게 숨김(Read로만 보임)
2-2. Skills (스킬)
SKILL.md + 리소스로 구성된 복잡한 기능 묶음. Claude가 상황에 맞춰 자동 발견해 실행. 여러 파일·스크립트·템플릿 포함 가능. (skill-creator로 생성·eval 벤치마크)
2-3. Subagents (서브에이전트)
/agents로 만드는 전용 에이전트. 독립 컨텍스트에서 특정 역할(리뷰·리서치·분석 등) 수행. 메인 대화 오염 없이 무거운 작업 위임. 병렬 다수 실행 가능.
2-4. Hooks (훅)
특정 이벤트에 스크립트 자동 실행. PreToolUse·PostToolUse·Stop·SessionStart·UserPromptSubmit·PreCompact 등. "X 할 때마다 자동으로 Y" 자동화는 메모리가 아니라 훅으로 구현 (harness가 실행).
2-5. MCP (Model Context Protocol)
외부 도구·데이터 소스 연결 규약. 연결 시 /mcp__서버__도구 형태 명령 자동 생성. 본 환경 예: Gmail·Calendar·Drive·Playwright·cua-driver.
2-6. Plugins (플러그인)
명령·스킬·훅·MCP를 묶어 배포하는 패키지. /plugin으로 설치·관리. 명령 네이밍 /플러그인명:명령명.
2-7. Custom Slash Commands (커스텀 명령)
.claude/commands/*.md(프로젝트) 또는 ~/.claude/commands/*.md(개인)에 두는 프롬프트 템플릿.
인자: $ARGUMENTS, $1·$2·$3
!명령 = bash 출력 삽입, @파일 = 파일 내용 삽입
frontmatter: description·argument-hint·allowed-tools·model·context: fork·disable-model-invocation·hooks
