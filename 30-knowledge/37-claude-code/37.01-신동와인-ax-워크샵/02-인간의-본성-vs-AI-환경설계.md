인간이 일을 잘 못하는 이유와 Claude Code + CLI 환경의 대응
배경: 왜 인간은 일을 잘 못하는가?
인간이 일을 해야만 생존할 수 있는 현대 사회에 살고 있지만, 우리의 생물학적 본성(DNA)은 현대의 노동 환경과 맞지 않게 설계되어 있습니다.
우리는 '수렵 채집 시절의 하드웨어(뇌)'를 가지고 '현대 자본주의의 소프트웨어(업무)'를 돌리려 하고 있습니다.
인간의 4가지 기제 vs Claude Code 시스템의 대응
1. 인지적 구두쇠 (Cognitive Miser) → "환경이 생각을 대신한다"
문제: 뇌는 에너지를 아끼려 합니다. 새로운 것보다 익숙한 것, 복잡한 것보다 단순한 것을 선호합니다. 중요한 일보다 쉬운 일을 먼저 하게 됩니다.
대응 맥락: 생각이 필요한 순간을 최소화하도록 환경 자체를 설계합니다.
Johnny Decimal 구조: "이 파일 어디에 둘까?" 고민이 없습니다
템플릿 시스템: 모든 시작점이 정해져 있습니다. 빈 화면 공포가 없습니다
슬래시 커맨드: /daily-note 치면 오늘 노트가 열립니다
핵심: 의사결정이 필요한 지점을 시스템이 미리 결정해둡니다.
2. 현재 편향 (Present Bias) → "즉각적 피드백의 설계"
문제: 인간은 미래의 큰 보상보다 지금의 작은 만족을 선택합니다. 업무 성과는 먼 미래에 나오지만, 스마트폰은 즉각적인 도파민을 줍니다.
대응 맥락: 작은 단위의 즉각적 완료감을 설계합니다.
파일 생성 = 완료의 신호: 바로 결과물이 보입니다
Cascade Automation: 3시간 작업이 10분 만에 완료됩니다
작은 성공의 도미노: 하나의 성공이 다음 성공으로 이어집니다
핵심: 보상 간격을 줄입니다. AI가 실행 속도를 높여주면, 미래의 보상이 "거의 지금"이 됩니다.
3. 위험 회피 (Loss Aversion) → "도전의 단가를 낮춘다"
문제: 완벽주의는 사실 실패 공포입니다. 도전 비용(시간, 에너지, 감정)이 높으면 신중해지고, 결국 시작조차 못 합니다.
대응 맥락: 한 번 시도하는 비용을 낮춰서 더 많이 도전합니다.
한 번 해보는 데 10분: 안 되면 다시 돌리면 됩니다
실험의 여유: 프롬프트 바꿔서 바로 실행, 결과 확인, 수정
작은 단위로 쪼개기: 큰 도전 하나 대신 작은 실험 열 번
핵심: 같은 시간에 더 많은 시도를 합니다. 더 많은 시도 = 더 많은 학습 = 더 나은 결과.
4. 사회적 연결 본능 (Social Connection) → "CLI 환경이 주의력을 보호한다"
문제: 뇌는 외부 자극에 자동으로 반응합니다. 알림, 화려한 인터페이스, 멀티태스킹 유혹. 딥 워크가 필요한데 계속 산만해집니다.
대응 맥락: 자극이 없는 환경에서 딥 워크가 강제됩니다.
검은 화면, 텍스트뿐: 뇌가 반응할 게 없습니다
알림 없음, 탭 없음: 산만해질 수가 없습니다
"지금 이 한 가지"에만 집중: 환경이 몰입을 만듭니다
핵심: CLI는 자극이 없습니다. 환경 자체가 딥 워크를 강제합니다.

의지력은 소모품입니다. 아침에 충전되고 저녁에 바닥납니다.

생각이 필요 없는 구조
